# ☁️ NT533 - Distributed Computing System

## 📌 Course Information
- **📛 Course Code:** NT533  
- **📖 Course Title:** Distributed Computing System  
- **🎓 Course Type:** Specialized course in Computer Networks and Data Communications (UIT)

## 📜 Course Description
This course introduces distributed systems and their services, such as file sharing, along with emerging trends in high-performance computing, including cluster computing, grid computing, and cloud computing. 

More specifically, it covers fundamental concepts and techniques for designing and implementing distributed computing systems. Technical topics include interprocess communication, remote procedure calls, distributed file systems, concurrency control, and more. 

### 🔍 **Key Topics**
- 🔄 Introduction to Distributed Systems  
- 📂 Distributed File Systems and File Sharing Services  
- 🌐 Interprocess Communication and Remote Procedure Calls (RPC)  
- 🔗 Concurrency Control Mechanisms  
- ☁️ Cloud Computing and Virtualization  
- 🖥️ Grid Computing and High-Performance Clusters  
- 🔄 Peer-to-Peer (P2P) Networking  
- 🌍 Web Services and APIs
